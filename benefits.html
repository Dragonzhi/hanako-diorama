STUDENT PERKS · 学生证就是钱
大部分福利用学校邮箱（edu 结尾）或学生认证即可领取。福利内容经常变动，领取前以官方页面为准。2026 年几个重要变化已标注：Copilot 学生计划暂停新注册、Cursor 免费 Pro 停止、Canva 学生权益下线。
必领 · GitHub Student Pack Core
GitHub Student Pack 一次认证解锁 90+ 服务的学生权益，含 GitHub Pro、JetBrains 全产品、DigitalOcean 200 美元、Azure 100 美元、免费域名等。用学校邮箱或学籍证明认证，约 72 小时通过 最优先
JetBrains 全家桶 IntelliJ IDEA、PyCharm 等全部 IDE 免费。1 年更新制，记得每年续认证，可走 GitHub Pack 或直接官网学生申请 免费
GitHub Copilot 2026 年 4 月起暂停学生计划新注册（官方称算力需求），暂停前认证的学生保留；新认证的目前给 Copilot Free。再开时间待官方公告 变化中
免费域名 Pack 内含免费域名权益（如 Namecheap .me 一年），申请后记得按时续期或转移，别让域名丢了 正好配域名计划
DigitalOcean 200 美元额度。注意 2026 年 6 月起 GPU 类服务不可用额度抵扣，普通 VPS 没问题 有时限，用到再领
Azure for Students 100 美元额度 + 25 项以上免费云服务，免信用卡 有时限
领取顺序建议

1. 先认证 GitHub Pack，立刻领 GitHub Pro 和 JetBrains（这两样一直在）。

2. 有时限的（DigitalOcean、DataCamp、GitKraken、免费域名）等真正要用的时候再领，别领了浪费。

3. 学生身份失效前，每年续一次 JetBrains 认证。
