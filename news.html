DeepSeek V4 Flash 正式版上线公测：轻量模型反超自家 Pro 预览版

7 月 31 日，DeepSeek 在 API 更新日志中悄然官宣 V4-Flash-0731 正式版。没有发布会，开发者圈却炸了锅：一个小参数模型，在 Agent 能力上全面反超自家旗舰预览版。

  • 总参数 284B（激活 13B），100 万 token 上下文；结构尺寸与预览版一致，仅重新后训练
  • 九项智能体/代码/自动化基准整体超越 V4-Pro 预览版：Terminal Bench 2.1 得 82.7，DeepSWE 54.4
  • 原生支持 OpenAI Responses API 格式，针对性适配 Codex，无需改 Base URL 即可切换
  • 100 万 token 场景单 token 推理计算量仅为 V3.2 的 27%，KV Cache 占用降至约 10%
  • OpenCode 数据显示其单日吞吐已达 8 万亿 token；V4-Pro 正式版「尽快发布」
